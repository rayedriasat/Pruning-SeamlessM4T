INPUT BATCH:
┌─────────────────────────────────────────────────────────────────────────────┐
│ • English audio:    [B, audio_len]          (e.g., "Hello, how are you?")  │
│ • Bengali text:     [B, text_len]           (e.g., "হ্যালো, কেমন আছেন?")   │
│ • Bengali audio:    [B, audio_len]          (target for unit extraction)   │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                        UNIT LABEL EXTRACTION                                │
│  (Done once in Phase 7 Cell 6, cached for Phase 8)                         │
│                                                                             │
│  Bengali audio → SeamlessM4T.generate() → .unit_sequences                  │
│                                                                             │
│  Output: Discrete unit IDs [B, unit_len]                                   │
│  Example: [234, 567, 123, 890, 456, ...]                                   │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                        FORWARD PASS (Phase 8)                               │
│                                                                             │
│  1. English audio → Speech Encoder → speech_hidden [B, speech_len, 1024]   │
│     [FROZEN - no gradient]                                                  │
│                                                                             │
│  2. speech_hidden → Text Decoder → text_hidden [B, text_len, 1024]         │
│     [FROZEN - no gradient]                                                  │
│                                                                             │
│  3. text_hidden → T2U Encoder → t2u_enc_hidden [B, text_len, 1024]         │
│     [TRAINABLE - receives gradient]                                         │
│                                                                             │
│  4. t2u_enc_hidden → T2U Decoder → unit_logits [B, unit_len, 10000]        │
│     [TRAINABLE - receives gradient]                                         │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                              LOSS COMPUTATION                               │
│                                                                             │
│  Unit Cross-Entropy Loss:                                                  │
│                                                                             │
│  loss = CrossEntropy(                                                       │
│      predicted = unit_logits,     # [B, unit_len, 10000]                   │
│      target    = unit_labels,     # [B, unit_len]                          │
│      ignore_index = -100          # Padding positions                      │
│  )                                                                          │
│                                                                             │
│  Expected loss progression:                                                 │
│    Initial: 7-8 (random predictions)                                        │
│    Final:   2-3 (learned unit patterns)                                     │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                            BACKWARD PASS                                    │
│                                                                             │
│  loss.backward()                                                            │
│                                                                             │
│  Gradient flows:                                                            │
│    unit_logits ← T2U Decoder ← T2U Encoder ← [STOP]                        │
│                                                                             │
│  Frozen components (no gradient):                                           │
│    • Speech Encoder                                                         │
│    • Text Decoder                                                           │
│    • Vocoder                                                                │
│                                                                             │
│  Trainable components (receive gradient):                                   │
│    • T2U Encoder (4 layers)                                                 │
│    • T2U Decoder (4 layers)                                                 │
│                                                                             │
│  Total trainable params: ~50-100M                                           │

PHASE 8 (T2U - Audio Recovery):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │

│                       FROZEN            FROZEN         ▲ TRAIN              │
│                                                        │                    │
│                                                        │                    │
│                                          Unit Loss (unit cross-entropy)     │
│                                                                             │
│  Speech Encoder & Text Decoder: Frozen (already fine-tuned)                │
│  T2U Model: IN gradient path → receives gradient                           │
│  Result: Audio quality recovered, text quality maintained                   │
│                                                                             │
