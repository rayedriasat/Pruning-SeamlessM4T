  LOSS COMPUTATION
═══════════════════════════════════════════════════════════════════════════════

  Combined Loss = (0.4 × S2TT_loss) + (0.6 × T2U_loss)
                   └─────────────┘    └──────────────┘
                   Text decoder       Audio pathway
                   (lower weight)     (higher weight)

  Why higher weight for T2U?
  → Audio output was broken in previous phases
  → T2U needs more training signal to recover
  → Text translation already works reasonably well

═══════════════════════════════════════════════════════════════════════════════
  TRAINING FLOW (Phase 7 Cell 9)
═══════════════════════════════════════════════════════════════════════════════

  For each batch:
    1. prepare_s2tt_batch() → audio features + text labels
    2. prepare_unit_batch() → audio features + unit labels
    
    3. compute_s2tt_loss() → text decoder CE loss
    4. compute_t2u_loss()  → T2U decoder CE loss (FIXED)
    
    5. loss = 0.4 × s2tt + 0.6 × t2u
    6. loss.backward()
    7. optimizer.step()
