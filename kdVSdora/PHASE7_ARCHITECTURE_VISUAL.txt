┌─────────────────────────────────────────────────────────────────────────────┐
│                         DoRA ADAPTER STRUCTURE                              │
└─────────────────────────────────────────────────────────────────────────────┘

Original Weight Matrix W [d_out, d_in]:
┌─────────────────────────────────────────────────────────────────────────┐
│  W = m × (V / ||V||)                                                    │
│      └─┘   └──────┘                                                     │
│   magnitude direction                                                   │
└─────────────────────────────────────────────────────────────────────────┘

DoRA Decomposition:
┌─────────────────────────────────────────────────────────────────────────┐
│  W_adapted = m × ((V + ΔV) / ||V + ΔV||)                               │
│               ↑     └──┬──┘                                             │
│               │        │                                                 │
│          magnitude   LoRA update                                        │
│          (trainable) (trainable)                                        │
│                                                                          │
│  where: ΔV = B × A                                                      │
│         B: [d_out, r]  (rank-8)                                         │
│         A: [r, d_in]   (rank-8)                                         │
│                                                                          │
│  Trainable params: d_out×r + r×d_in + 1 (magnitude)                    │
│                    ≈ 2×d×r  (much smaller than d²)                      │
└─────────────────────────────────────────────────────────────────────────┘

Example (1024 → 1024 projection):
  Original:     1024 × 1024 = 1,048,576 params
  DoRA (r=8):   1024×8 + 8×1024 + 1 = 16,385 params
  Reduction:    98.4% fewer params!

┌─────────────────────────────────────────────────────────────────────────────┐
│                    DISTILLATION LOSS COMPUTATION                            │
└─────────────────────────────────────────────────────────────────────────────┘

Teacher Logits [B, T, 10082]:
┌────────────────────────────────────────────────────────────────────────┐
│  [2.3, 1.1, 0.5, ..., -0.3]  ← Raw logits from teacher T2U            │
│         ↓                                                               │
│  Softmax(logits / temperature)                                         │
│         ↓                                                               │
│  [0.23, 0.15, 0.11, ..., 0.01]  ← Soft targets (smooth distribution)  │
└────────────────────────────────────────────────────────────────────────┘

Student Logits [B, T, 10082]:
┌────────────────────────────────────────────────────────────────────────┐
│  [1.8, 0.9, 0.3, ..., -0.5]  ← Raw logits from student T2U            │
│         ↓                                                               │
│  LogSoftmax(logits / temperature)                                      │
│         ↓                                                               │
│  [-1.47, -1.90, -2.21, ..., -4.61]  ← Log probabilities               │
└────────────────────────────────────────────────────────────────────────┘

Soft Loss (KL Divergence):
┌────────────────────────────────────────────────────────────────────────┐
│  KL(teacher || student) = Σ teacher[i] × log(teacher[i] / student[i]) │
│                         = Σ teacher[i] × (log(teacher[i]) - log(student[i])) │
│                                                                         │
│  Scaled by temperature²: loss × (T²) = loss × 4.0                     │
│  (Compensates for softening effect)                                    │
└────────────────────────────────────────────────────────────────────────┘

Hard Loss (Cross-Entropy):
┌────────────────────────────────────────────────────────────────────────┐
│  Hard targets = argmax(teacher_logits)  ← [B, T] indices              │
│  CE(student_logits, hard_targets)                                      │
│  (Provides stability, prevents mode collapse)                          │
└────────────────────────────────────────────────────────────────────────┘

Combined Loss:
┌────────────────────────────────────────────────────────────────────────┐
│  loss = 0.7 × soft_loss + 0.3 × hard_loss                             │
│         └──────────────┘   └──────────────┘                           │
│         Rich supervision   Stability                                   │
└────────────────────────────────────────────────────────────────────────┘

   ✅ Adds low-rank adapters to encoder + decoder
   ✅ Only 3% of params trainable
   ✅ Recovers text quality to 90-95%
   ✅ Proven to work in your previous experiments

   ✅ Teacher on CPU (no VRAM usage!)
   ✅ Student on GPU (only T2U trains)
   ✅ Soft targets richer than hard units
   ✅ Recovers audio quality to 80-85%

   ✅ Phase 7a: 7.4 GB VRAM (fits in T4)
   ✅ Phase 7b: 6.4 GB VRAM (fits in T4)
